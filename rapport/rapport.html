Ce que ce document est — et ce qu'il n'est pas

Ceci est un pré-audit automatisé. Il exécute les tests techniques de la norme WCAG 2.1 A/AA avec le moteur axe-core, sur 3 page(s) de votre site. Les tests automatisés couvrent environ un tiers des critères RGAA : ils détectent les erreurs de code objectives, pas la pertinence éditoriale. Ce document ne constitue pas une attestation de conformité RGAA et ne remplace pas un audit réalisé par un expert. Les critères qui exigent un jugement humain sont listés plus bas.

Non-conformités détectées

Bloquant

Les images doivent avoir une alternative textuelle

Vérifier que les éléments <img> ont une alternative textuelle, ou un rôle de type 'none' ou 'presentation'

  • 1 élément(s) concerné(s) sur 1 page(s)
  • Critère WCAG : 1.1.1
  • Critère RGAA indicatif : 1.1
  • Règle technique : image-alt

Exemples d'éléments à corriger :

  • #mwAsU
    <img resource="https://fr.wikipedia..." src="//upload.wikimedia.o..." decoding="async" loading="lazy" data-file-width="240" data-file-height="320" data-file-type="bitmap" height="320" width="240" class="mw-file-element" id="mwAsU">

    Corriger l’un des éléments suivants : L’élément n’a pas d’attribut alt L’attribut aria-label n’existe pas ou est vide L’attribut aria-labelledby n’existe pas, fait référence à des éléments qui n’existent pas ou à des éléments vides ou non visibles L’élément n’a pas d’attribut title La sémantique par défaut de l’élément n’a pas été remplacée par role="none" ou role="presentation"

Majeur

Les éléments doivent avoir un contraste de couleurs suffisant

Vérifier que les contrastes entre le premier plan et l’arrière-plan rencontrent les seuils de contrastes exigés par les WCAG 2 AA

  • 3 élément(s) concerné(s) sur 2 page(s)
  • Critère WCAG : 1.4.3
  • Critère RGAA indicatif : 3.2 / 3.3
  • Règle technique : color-contrast
